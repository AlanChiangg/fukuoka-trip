# fukuoka-trip

靖雅的福岡任務簿：群益期貨 福岡 5 日（2026/11/4 – 11/8）活動總召備忘。

單一 `index.html`，透過 GitHub Pages 發佈：
https://alanchiangg.github.io/fukuoka-trip/

- 每天該做的任務、要點收的數量、要留意的錢，都做成勾選和計數器，存在自己手機裡。
- 加到手機主畫面後可離線開啟（`sw.js` 快取；改了 `index.html` 記得把 `sw.js` 的 `VERSION` 加 1）。
- 預覽旅途中某個時刻：網址加 `?now=2026-11-06T17:30`（日本時間）。
